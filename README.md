# HomeRun

The household hub for meals, groceries, chores and daily goals. A phone-shaped
window onto a folder of markdown notes: an Obsidian vault if you use Obsidian,
a plain directory if you do not.

There is no database and no cloud account. Every screen reads and writes the
markdown directly, so the notes stay the single source of truth and everything
remains editable in any editor.

**Setting this up for your own household?** Hand this repo to Claude Code and
say "set this up for me following SETUP.md", or follow
[SETUP.md](SETUP.md) yourself. The short version:

```
npm install
node bin/setup.mjs             # four questions: two names, a folder, a PIN
npm test && npm run build && npm start
```

Read [SETUP.md](SETUP.md) for the optional pieces (phone access over
Tailscale, add-to-home-screen, the morning email via Resend, the budget tab,
AI recipe import, one-tap grocery cart building via orders-sidecar/) and for how to bulk-import recipes from Pinterest or TikTok.
Read [FORHomeRun.md](FORHomeRun.md) for the full tour, and
[.claude/napkin.md](.claude/napkin.md) for the sharp edges.

## One-time setup for the Claude features

The chat planner, recipe import and grocery generator run the `claude` CLI as a
subprocess. It will refuse to use this repo's permission allowlist until the
workspace is trusted, and it fails quietly when it does. Run once:

```
cd <path to this repo> && claude
```

accept the trust prompt, then /exit. The app detects this state and tells you
if it has not been done. Note that `.claude/settings.json` is generated by
`bin/setup.mjs` from its `.template` - it must contain this machine's absolute
paths or every AI job silently writes nothing.

## Commands

```
npm run dev         # dev server on port 3010
npm run build       # production build
npm start           # production server on port 3010
npm test            # parser tests (no framework, runs in under a second)
npm run typecheck   # tsc --noEmit
```

## The tabs

- **Week** - the meal plan as day cards. Tap any meal to set a dish, a recipe
  link, leftovers, a restaurant, or who is cooking. Manage handles drafts,
  templates and archiving.
- **Plan** (from Week or More) - the chat planner. It opens by asking what is
  in the fridge, freezer and pantry, then builds the week around it so the
  perishables get used first. Proposals land in Weeks/Drafts.
- **Recipes** - searchable and filterable, with per-person star ratings, a
  servings scaler, comments, and import from a URL.
- **Grocery** - generate from the week, tap to check off, copy as plain text for
  Reminders or the store app.
- **Honeydew** - household tasks with due dates, owners and recurrence.
  Completing a repeating task writes the next one automatically.
- **More** - staples, restaurants, ingredient preferences, and who you are.

## Installing on a phone

The Mac serves on the LAN at `http://<mac>.local:3010`. Open it in Safari or
Chrome and use Add to Home Screen; the manifest and icons make it launch
standalone.
